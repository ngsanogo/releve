# ADR 0001 — Apache-2.0, written from scratch

Date: 2026-09-13 · Status: accepted

## Context

releve is meant to be read, forked and reused by anyone running it at home.

## Decision

Release it under **Apache-2.0**: permissive, with an explicit patent grant, and
common for infrastructure software. The code is written from scratch; the only
external facts it relies on are the gateway's public API paths and the shape of
its answers.

## Consequences

- Anyone can use, modify and redistribute it, including in other projects.
- Contributions come under the same license.
